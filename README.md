# Scroll-V

Smooth scrolling for all Windows applications. Free and open-source.

## Download & Install

1. Install [.NET 8.0 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (if not already installed).
2. Download `Scroll-V.zip` from [Releases](https://github.com/w00tdev/Scroll-V/releases) and extract it.
3. Run `Scroll-V.exe`.

Requires Windows 10 or 11 (64-bit).

## How to Use

- **Customize feel**: Adjust Smoothness, Scroll Speed, Momentum, Glide, and Animation curve directly in the app.
- **Exclude specific apps**: Add apps (like games, video players, or CAD tools) to the exclusion list if you want normal scrolling in them.
- **Zoom normally**: Hold `Ctrl` while scrolling to zoom in browsers and editors without smooth scroll interfering.
- **Run in background**: Closing the window minimizes Scroll-V to the system tray (uses ~6 MB RAM). Double-click the tray icon to reopen settings, or enable **Start with Windows** to run it automatically.
- **Language**: Switch between English and Vietnamese in the top corner.
